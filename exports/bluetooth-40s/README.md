# Cómo funciona el Bluetooth

[Descargar el MP4](https://github.com/astroyw/videos/raw/refs/heads/main/exports/bluetooth-40s/como-funciona-el-bluetooth.mp4)

Reel de 40 segundos, 1080×1920, 30 FPS, H.264. Animación continua con celular, auriculares, paquetes y un detalle del salto de canales. Subtítulos en español y CTA final; sin voz ni pista de audio.

Los 14 pulsos de texto comparten un mundo visual que permanece durante todo el video. Los objetos se desplazan para mostrar el mecanismo y vuelven al conjunto, con cero cortes de montaje entre escenas.

- [Subtítulos SRT](./subtitulos.srt)

- [Proyecto editable Remotion + HyperFrames](./proyecto-bluetooth-40s.zip)
- [Fuentes y simplificaciones](./FUENTES.md)

Los canales y tiempos del diagrama son ilustrativos. No es una captura de tráfico real. El enlace Bluetooth no necesita internet; una aplicación de streaming puede necesitarlo para obtener el contenido.

Si GitHub abre la vista del archivo, usar **Download raw file**. Los subtítulos ya están incrustados; el SRT sirve para ajustar el montaje cuando se agregue una grabación de voz.
