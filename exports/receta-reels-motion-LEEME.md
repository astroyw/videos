# Receta de motion graphics para Reels, Shorts y TikTok

[Descargar el ZIP](https://github.com/astroyw/videos/raw/refs/heads/main/exports/receta-reels-motion.zip)

Descomprimí y abrí `00-EMPEZA-ACA.md`. Editá el tema y la idea central en `01-PROMPT-EDITABLE.md` y pegá el prompt completo en Claude Code o Codex con acceso a la carpeta.

Incluye receta de producción, prompt editable en MD/TXT, guía visual, fórmulas de hook/retención/CTA, ejemplo de storyboard, instrucciones para skills y un proyecto Remotion + HyperFrames con demo renderizada y verificada.

Base editable: 40 segundos, 14 partes, vertical 1080×1920, 30 FPS, sin audio, subtítulos y una CTA final. Sin números de slide. El ejemplo conserva sus fuentes y licencias y no incluye los videos originales de referencia.

La guía visual se basa en los dos archivos que pudieron inspeccionarse. El video de Tierra plana excedió el límite de transferencia de 32 MiB; el alcance está documentado dentro del ZIP.

Si GitHub muestra la vista del archivo, usá **Download raw file** para guardar el ZIP.
