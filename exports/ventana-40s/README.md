# Cómo se fabrica una ventana

[Descargar el MP4](https://github.com/astroyw/videos/raw/refs/heads/main/exports/ventana-40s/como-se-hace-una-ventana.mp4)

Video educativo sobre una ventana de aluminio abatible. **40 segundos exactos, 1080 × 1920, 30 FPS, H.264.** Motion graphics con 14 partes, subtítulos en español, énfasis amarillo y cierre para compartir. Sin voz, música, pista de audio ni números de slide.

- [Verificación técnica](./VERIFICACION.md)

Si GitHub muestra una vista del archivo, usá **Download raw file** para guardarlo. Los subtítulos ya están incrustados; el SRT permite ajustar los tiempos cuando agregues tu voz.

Los diagramas son esquemáticos. Los perfiles, mecanizados y accesorios reales dependen del sistema del fabricante; este Reel explica el proceso general y no es un manual de taller.
