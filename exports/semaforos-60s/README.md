# Cómo cambian de luz los semáforos

Reel de 60 segundos, 1080×1920, 60 FPS, MP4 H.264 + AAC. Voz sintética argentina, subtítulos karaoke centrados en el tercio superior y animación continua de un cruce, su controlador y una avenida.

Archivo final: `como-cambian-los-semaforos.mp4`. Si GitHub abre el reproductor, usar Descargar o Guardar video como. `semaforos-proyecto-editable.zip` contiene fuentes, assets, instrucciones, guion y licencias; no incluye node_modules ni modelos de voz. ZIP verificado con CRC. El SRT es adicional: el MP4 ya tiene los subtítulos quemados.

Ver `VERIFICACION.md` para pruebas y límites. No se realizó escucha humana de la voz. Los tiempos del semáforo son ilustrativos.
